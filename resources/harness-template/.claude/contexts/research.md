# Research Context

조사 모드 — 코드 수정 없이 분석/탐색에 집중.

## 활성화 에이전트
- docs-lookup (공식 문서 검색)
- tech-architect (아키텍처 분석)
- planner (피처 계획)

## 워크플로우
1. 문제/요구사항 정의
2. 공식 문서 및 API 레퍼런스 조사
3. 기존 코드베이스 탐색 (패턴 파악)
4. 선택지 비교 분석
5. 결론 + 구현 계획 도출

## 허용
- WebSearch, WebFetch 적극 활용
- 기존 코드 읽기 전용
- PRD/스펙 문서 초안 작성

## 비활성
- 코드 수정 (Edit/Write 최소화)
- 빌드/테스트 실행
- 커밋/푸시
