# Skill Stocktake

하네스의 스킬, 커맨드, 에이전트 품질을 감사한다.

## 감사 항목

### 1. 파일 존재 체크
- CLAUDE.md에 명시된 에이전트가 실제 파일로 존재하는가
- CLAUDE.md에 명시된 커맨드가 실제 파일로 존재하는가
- CLAUDE.md에 명시된 스킬이 실제 파일로 존재하는가

### 2. 내용 품질 체크
- 에이전트: tools, model, 규칙이 정의되어 있는가
- 스킬: 실제 코드 예제가 포함되어 있는가
- 커맨드: 입력/출력 형식이 명확한가

### 3. 정합성 체크
- Agent Routing 테이블과 실제 에이전트 파일 일치
- Skill Routing 테이블과 실제 스킬 파일 일치
- 커맨드 목록과 실제 커맨드 파일 일치

### 4. 중복/누락 체크
- 역할이 겹치는 에이전트 탐지
- 참조되지 않는 (고아) 스킬/에이전트
- 커맨드에서 호출하지만 없는 에이전트

## 실행

```
harness-optimizer 에이전트에게 위임하거나 수동:

1. Glob으로 모든 에이전트/스킬/커맨드 파일 목록
2. CLAUDE.md 파싱하여 명시된 목록 추출
3. 교차 비교
4. 결과 보고
```

## 출력

```markdown
## Stocktake Report

### 에이전트 (N/M 일치)
- OK: agent-a, agent-b, ...
- MISSING: agent-x (CLAUDE.md에 있지만 파일 없음)
- ORPHAN: agent-y (파일 있지만 CLAUDE.md에 없음)

### 스킬 (N/M 일치)
- ...

### 커맨드 (N/M 일치)
- ...

### 권장 조치
1. ...
```
