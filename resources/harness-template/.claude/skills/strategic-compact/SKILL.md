# Strategic Compact

컨텍스트 윈도우 압축 전 상태를 보존하는 전략.

## 문제

Claude Code는 컨텍스트 한계에 도달하면 자동 압축한다.
압축 시 중요한 결정사항, 진행 상태, 디버깅 컨텍스트가 손실될 수 있다.

## 보존 전략

### PreCompact 훅 (`pre-compact.sh`)
자동 압축 직전에 실행되어 핵심 상태를 파일로 저장.

저장 위치: `/tmp/claude-compact-state/`

### 보존 항목
1. **현재 작업 상태** — 무엇을 하고 있었는지
2. **결정 사항** — 왜 이 접근법을 선택했는지
3. **실패한 시도** — 무엇을 시도했고 왜 실패했는지
4. **다음 단계** — 다음에 무엇을 해야 하는지
5. **열린 파일 목록** — 작업 중이던 파일들

### 수동 컴팩션 제안 타이밍
- 대규모 코드 읽기 후 (10+ 파일)
- 복잡한 디버깅 세션 중
- 아키텍처 결정 후
- 에이전트 체이닝 중간

## 복원 프로세스

압축 후 자동으로:
1. `/tmp/claude-compact-state/` 읽기
2. 핵심 컨텍스트 요약 주입
3. 작업 재개

## 규칙
- 코드 전문은 저장하지 마라 (파일 경로만)
- 결정의 "왜"를 반드시 포함
- 최대 2000자 이내로 압축
