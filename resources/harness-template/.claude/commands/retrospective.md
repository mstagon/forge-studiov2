이번 세션의 회고를 실행한다.

## 1. 세션 분석

```bash
git log --oneline --since="today" 2>/dev/null || git log --oneline -20
git diff --stat HEAD~5..HEAD 2>/dev/null
```

## 2. 체크리스트

### 오케스트레이션 효율
- [ ] 에이전트 체이닝이 올바른 순서로 실행됐는가?
- [ ] 불필요한 에이전트 호출이 있었는가?
- [ ] 병렬 실행 가능했던 것을 순차로 했는가?
- [ ] Cross-Stack sync가 누락된 곳이 있는가?

### 품질
- [ ] Critical 이슈가 리뷰에서 잡혔는가? (사전에 못 막은 것은?)
- [ ] 테스트 커버리지는 충분한가?
- [ ] 밸런스 수치가 하드코딩된 곳은 없는가?

### 실수 패턴
- [ ] 반복된 실수가 있는가?
- [ ] CLAUDE.md 규칙을 위반한 적이 있는가?
- [ ] 새로 발견된 안티패턴이 있는가?

## 3. 교훈 기록

발견된 교훈을 `docs/lessons-learned.md`에 기록:

```markdown
### YYYY-MM-DD: [교훈 제목]
- **상황**: 무엇을 하고 있었는가
- **문제**: 무엇이 잘못됐는가
- **원인**: 왜 발생했는가
- **해결**: 어떻게 고쳤는가
- **방지**: 재발 방지 방법
```

## 4. 자기개선 (Escalation)

`docs/lessons-learned.md`에서 3회 이상 반복된 패턴을 찾아:
→ CLAUDE.md "금지 패턴" 섹션에 추가 제안
→ 해당 스킬 또는 에이전트 규칙 업데이트 제안
→ 훅으로 자동 차단 가능하면 settings.json 훅 추가 제안

## 5. 하네스 개선 제안

- 새로운 스킬이 필요한가?
- 기존 에이전트의 역할 범위 조정이 필요한가?
- 오케스트레이션 체인 순서 변경이 필요한가?
- 새로운 훅이 도움이 될까?
