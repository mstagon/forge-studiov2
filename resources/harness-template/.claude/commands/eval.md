"$ARGUMENTS" 기준으로 현재 구현을 평가한다.

## 프로세스

1. **평가 기준 로드**: `eval-harness` 스킬 참조
2. **코드 품질 평가** (40%): 타입 안전, 에러 핸들링, 네이밍
3. **테스트 평가** (25%): 커버리지, 핵심 경로
4. **아키텍처 평가** (20%): 레이어 규칙, 단일 책임
5. **보안 평가** (15%): 인증, 입력 검증, 인젝션
6. **총점 산정 + 등급**

## 모드

- `/eval` — 현재 변경사항 평가
- `/eval spec` — 스펙 대비 완성도 평가
- `/eval security` — 보안 집중 평가

```markdown
## Evaluation Report

| 코드 품질 | 35/40 | any 타입 1건 |

| 아키텍처 | 18/20 | OK |
| 보안 | 13/15 | OK |
| **총점** | **86/100** | **등급: B** |

### 개선 필요
1. any 타입 제거 (game.service.ts:42)
2. 테스트 커버리지 80% 달성 필요
```
